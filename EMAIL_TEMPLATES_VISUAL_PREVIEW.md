## 🔄 Template Customization Quick Guide

### Change Header Color:

```css
.header {
  background: linear-gradient(135deg, #NEW_COLOR1 0%, #NEW_COLOR2 100%);
}
```

### Change Code Color:

```css
.code {
  color: #NEW_COLOR;
}
```

### Change Text:

```java
// In EmailService.java
String message = "Your custom message here";
```

### Add Company Logo:

```html
<img
  src="https://your-domain.com/logo.png"
  style="height: 30px; margin: 10px 0;"
/>
```

### Change Footer Text:

```java
<div class="footer-text">Your company info here</div>
```

## 🔒 Security Features

✅ **Implemented:**

- No passwords/sensitive data in email body
- Secure HTML structure (no script tags)
- UTF-8 encoding prevents injection
- Error messages don't expose system info
- Code expiry built-in

🛡️ **Best Practices Followed:**

- Separation of concerns
- Error handling without data leaks
- Proper character encoding
- HTML sanitization (no user input in templates)
